Serendipity Drift 가이드

Chrome Built-in AI(Gemini Nano)와 크롬 검색창을 활용한 온디바이스 사유 탈선 탐색기

🚀 크롬 내장 Gemini Nano 모델 활성화 방법 (최초 1회)

Chrome 128 이상 버전에서는 기기 내부에 경량 AI 모델(Gemini Nano)을 활성화하여 백엔드 없이 무료로 호출할 수 있습니다.

  1. Prompt API 플래그 켜기:
    아래 주소를 복사하여 새 탭 주소창에 붙여넣고 이동한 뒤, 설정을 Enabled로 변경합니다.
    chrome://flags/#prompt-api-for-gemini-nano
  2. 사양 제한 우회 플래그 켜기:
    아래 주소로 이동하여 설정을 Enabled BypassPerfRequirement로 변경합니다.
    chrome://flags/#optimization-guide-on-device-model
  3. Chrome 완전 재시작:
    브라우저 우측 하단에 뜨는 [Relaunch (다시 시작)] 버튼을 눌러 크롬을 재시작합니다.
  4. 컴포넌트에서 모델 다운로드 확인:
    크롬 주소창에 아래 주소로 접속한 뒤 Optimization Guide On Device Model 항목의 [Check for update (업데이트 확인)]을 누릅니다. 모델(약 1~2GB) 다운로드가 완료되면 상태가 Up-to-date로 바뀝니다.
    chrome://components
💡 팁: 모델 다운로드 대기 중이거나 플래그를 아직 켜지 않은 환경에서도, 확장 프로그램에 내장된 자체 휴리스틱 연상 알고리즘으로 즉시 끊김 없이 동작합니다!

⚡ 크롬 검색창을 활용하는 3가지 탐색 방법

  • 1. 크롬 주소창(Omnibox)에서 바로 비틀기:
    주소창에 drift 검색어 (예: drift 인공지능)를 입력하면, 1~4단계 비틀린 검색어가 주소창 자동완성에 즉시 추천됩니다. 엔터를 치면 해당 검색어로 구글 검색창이 바로 열립니다.
  • 2. 구글 검색 결과 페이지에서 바로 발견:
    구글 검색창에서 평소처럼 검색하면 결과 상단에 [비틀린 사유의 궤적] 바가 주입됩니다. 4단계 칩을 클릭해 즉시 이동하거나, 다른 사유 벡터로 재셔플할 수 있습니다.
  • 3. 사이드패널 카드 스택 & 사유의 가지치기:
    브라우저 사이드패널을 열어 20가지 철학적·예술적 사유 벡터를 직접 선택하고, [🌱 이 조각으로 도약]을 눌러 꼬리에 꼬리를 무는 사유의 궤적(Breadcrumb)을 이어갈 수 있습니다.
