Serendipity Drift 가이드

Chrome Built-in AI(Gemini Nano)와 크롬 검색창을 활용한 온디바이스 사유 탈선 탐색기

🚀 Gemini Nano 모델 준비하기 (최초 1회)

Chrome 138 이상에서는 확장 프로그램이 내장 AI(Prompt API)를 플래그 없이 사용할 수 있습니다. 모델(Gemini Nano, 수 GB)만 한 번 내려받으면 이후에는 인터넷 없이도 기기 안에서 동작합니다.

  1. Chrome 최신 버전으로 업데이트:
    아래 주소에서 버전을 확인하고 업데이트한 뒤 다시 시작합니다. (138 이상 필요)
    chrome://settings/help
  2. 기기 내 AI 설정 켜기:
    설정 → 시스템 → 기기 내 AI(On-device AI)가 켜져 있는지 확인합니다. 꺼져 있으면 모델을 내려받지 않고, 이미 받은 모델도 삭제됩니다.
    chrome://settings/system
  3. WebAI Studio 확장으로 모델 받기 (권장):
    Chrome 공식 문서가 안내하는 개발자 도구 확장입니다. 설치한 뒤 아무 페이지에서 F12(개발자 도구) → WebAI 탭을 엽니다.
    • Overview / Dashboard: Gemini Nano 상태(Ready, Downloadable 등)를 확인하고 모델 다운로드를 진행합니다.
    • Diagnosis: 모델이 받아지지 않을 때 원인(기기 조건, 설정 등)을 진단합니다.
    https://web-ai.studio/extension
  4. 설치 확인:
    아래 페이지에서 모델 상태와 크기를 확인할 수 있습니다. 오류가 있으면 Broker State 탭을 확인하세요.
    chrome://on-device-internals
    준비가 끝나면 이 확장의 팝업과 사이드패널 상태 배지가 "Gemini Nano 준비됨"으로 바뀝니다.
💡 다른 방법: 모델 상태가 "다운로드 가능"일 때는 이 확장의 팝업 상태 카드나 사이드패널의 [모델 받기] 배지를 클릭해도 다운로드가 시작됩니다. (Chrome 정책상 모델 다운로드는 사용자 클릭이 있어야 시작됩니다.) 모델을 쓸 수 없는 동안에는 내장 연상 키워드로 동작하며, 결과에 내장 연상 모드 표시가 붙습니다.

🖥️ 기기 요구사항

모델이 받아지지 않는다면 대부분 아래 조건 때문입니다. (Chrome 공식 문서 기준이며 버전에 따라 바뀔 수 있습니다.)

  • 운영체제: Windows 10/11, macOS 13 이상, Linux, 또는 Chromebook Plus (모바일은 지원하지 않음)
  • 저장 공간: Chrome 프로필이 있는 드라이브에 여유 공간 22GB 이상. 다운로드 뒤 여유 공간이 10GB 아래로 줄면 모델이 자동 삭제됩니다.
  • GPU 또는 CPU: VRAM 4GB를 넘는 GPU, 또는 RAM 16GB 이상 + 4코어 이상 CPU
  • 네트워크: 첫 다운로드 때만 데이터 제한이 없는 연결이 필요합니다.
조건을 만족하지 않는 기기에서도 확장 프로그램은 내장 연상 모드로 계속 동작합니다.

🛠️ 모델이 준비되지 않을 때

  1. Chrome을 완전히 종료했다가 다시 시작합니다.
  2. chrome://settings/system에서 기기 내 AI가 켜져 있는지 다시 확인합니다.
  3. chrome://on-device-internals에서 다운로드가 진행 중인지 확인합니다. 첫 다운로드는 시간이 걸릴 수 있습니다.
  4. 개발자 도구 콘솔(F12 → Console)에서 아래를 실행해 "available"이 나오는지 확인합니다.
    await LanguageModel.availability()
  5. WebAI Studio의 Diagnosis 탭에서 원인을 확인합니다.
사양 조건을 아슬아슬하게 못 넘는 기기라면 최후 수단으로 chrome://flags/#optimization-guide-on-device-model을 Enabled BypassPerfRequirement로 바꿔 볼 수 있습니다. 실험 기능이라 동작이 느리거나 불안정할 수 있습니다.

⚡ 사용 방법

  • 1. 주소창(Omnibox)에서 바로 비틀기:
    주소창에 drift 검색어 (예: drift 인공지능)를 입력하면 1~4단계 비틀린 검색어가 자동완성으로 추천됩니다. Enter를 누르면 그 검색어로 구글 검색이 열립니다.
  • 2. 구글 검색 페이지에서 바로 발견:
    평소처럼 구글에서 검색하면 결과 위에 [비틀린 사유의 궤적] 위젯이 나타납니다. 단계 카드를 누르면 그 검색어로 이동하고, 🎲 다른 각도로 다른 사유 벡터를 적용할 수 있습니다. 구글 이미지·동영상 탭에서는 단계마다 썸네일 4개를 미리 보여줍니다.
    사이드패널이 열려 있는 창에서는 위젯을 띄우지 않습니다. 비틀기는 사이드패널이 맡고, 본창에는 원래 검색 결과만 보여줍니다.
  • 3. 사이드패널에서 이미지·동영상·텍스트로 탐색:
    사이드패널에서 20가지 사유 벡터를 고르고 보기 방식을 선택합니다.
    • 🖼️ 이미지: 단계마다 썸네일 4장. 클릭하면 확대 보기, "원본 페이지 ↗"는 본창으로 엽니다.
    • 🎬 동영상: 단계마다 YouTube 영상 4개. 클릭하면 본창에서 재생합니다.
    • 📝 텍스트: 비틀린 검색어와 설명 카드.
    이미지·동영상 모드에서 비틀기를 실행하면 원래 검색어의 정확한 결과(0단계)가 본창의 구글 이미지·동영상 탭에 함께 열립니다. 🌱 이 조각으로 도약을 누르면 그 검색어에서 다시 비틀며 사유의 궤적을 이어갑니다.
